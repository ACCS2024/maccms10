域名批量更新教程（MacCMS v10）

当站点域名更换后，需将旧域名替换为新域名，否则视频将无法播放。
  1. 登录 MacCMS v10 后台管理系统
  2. 在左侧菜单找到 数据库 → 数据批量替换
  3. 数据表选择 mac_vod
  4. 替换字段选择 vod_play_url
  5. 在「查找内容」填写 旧域名（如 http://old.example.com）
  6. 在「替换为」填写 新域名（如下方所示）
  7. 点击「执行替换」，完成后清除网站缓存

当前解析地址（新域名）

{$cfg.player_host}
注意：批量替换操作不可逆，建议操作前先备份数据库！

SeaCMS 配置教程

SeaCMS 采集接口与 MacCMS 格式不同，请注意使用正确的接口地址。导入播放器后还需手动对应绑定分类，否则部分分类视频无法正常播放。

采集接口（SeaCMS 专用）

采集接口 {$cfg.api_host}api.php/Seacms/vod/
M3U8解析接口 {$cfg.player_host}

播放器安装步骤（SeaCMS v9.0+）

  1. 下载下方 seacms.zip 文件并解压
  2. 将解压得到的 seacms/bfzym3u8.html 上传至 SeaCMS 网站根目录下对应播放器目录
  3. 登录 SeaCMS 后台 → 系统设置 → 播放器管理 → 新增播放器
  4. 播放器文件路径填写 bfzym3u8.html，名称自定义
  5. 在分类管理中将对应分类绑定到此播放器
  6. 清除缓存，验证播放

MaxCMS 配置教程

MaxCMS 需手动修改两个文件来添加解析播放器，相关文件需联系站长获取。
M3U8解析接口 {$cfg.player_host}
播放器标识 {$cfg.player_flag}

修改 admin/imgs/main.js

在 main.js 中找到播放器列表数组，添加如下条目（name 与 value 保持一致）：

{literal}{"name": "{$cfg.player_flag}", "value": "{$cfg.player_flag}"}{/literal}
注意 JSON 格式，最后一项不加逗号，否则旧版 IE 会报错。

修改 inc/playerKinds.xml

在 playerKinds.xml 的 <players> 节点内追加：

<player> <kind>{$cfg.player_flag}</kind> <parse>{$cfg.player_host}</parse> </player>
  1. 修改并保存以上两个文件后，上传覆盖服务器对应文件
  2. 登录 MaxCMS 后台清除缓存
  3. 刷新前台，选择对应播放器验证播放
文件修改有风险，建议操作前备份原文件。如需原始模板文件请联系站长手动获取。

爱影CMS 配置教程

播放器标识 {$cfg.player_flag}

配置步骤

  3. 采集接口地址填写上方 XML采集接口，选择 XML 格式

如果视频播放异常，请检查播放器标识是否与采集来的 flag 字段一致。

新闻 & 演员接口说明

以下接口为独立新闻和演员数据接口，可在支持自定义接口的 CMS 中配置使用。

新闻接口

https://news.bfzyapi.com/api.php/provide/art/

演员接口

http://news.bfzyapi.com/api.php/provide/actor/

接口使用说明

  1. 登录 CMS 后台，进入采集或内容源设置
  2. 新增数据源，接口格式选择 XML
  3. 新闻内容使用「新闻接口」地址；演员数据使用「演员接口」地址
  4. 设置采集频率（建议每日一次），保存后执行首次采集
  5. 采集完成后在前台验证新闻列表和演员页面是否正常展示
注意：演员接口为 HTTP 协议，若网站为 HTTPS，浏览器可能因混合内容策略阻止加载，建议在服务器端进行数据同步而非前端直接调用。

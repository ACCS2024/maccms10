添加采集步骤

  1. 后台 → 采集 → 采集源管理 → 添加采集源

MacCMS v10 — 播放器安装

  1. 下载下方 mac10.zip 并解压，得到 mac10/bfzym3u8.txt
  2. 后台 → 系统 → 播放器管理 → 点击「导入」
  3. 上传 bfzym3u8.txt，导入成功后可在播放器列表看到新条目
  4. 后台 → 系统 → 缓存管理 → 清除全部缓存
  5. 前台播放任意视频，验证播放正常
{if $files.mac10} 下载播放器文件 mac10.zip {else/}
播放器文件尚未生成，请联系管理员在后台点击「重新生成文件」。

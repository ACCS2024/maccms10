# 杏吧资源站 V2

从 2026-09-09 线上 `m1938pc3` 的 277 个文件建立独立副本，保留已确认的原站布局和 Logo。模板目录为 `m1938pc3_v2`，HTML 目录仍为 `html9`。

## 已二开的页面

- 首页、影片首页／分类／筛选列表／搜索：真实 MACCMS 标签和原 URL 生成函数；首页 70 条，其他列表 40 条。
- 图文首页／分类／筛选列表／搜索／详情：真实分类、内容和文章分页。
- 影片详情：分来源地址列表、部分选择、全选、倒序、批量复制、报错及逐集播放链接。
- 播放页面外层：统一页头和响应式容器；内部 `player_data`、`player_js` 和权限判断沿用原系统。
- 共享页头：桌面七行分类；移动端横向可滑动 Tab，仅显示当前子分类面板，自动定位当前分类所属组，支持键盘切换。
- 首页公告和接口：原公开地址集中在 `settings.php`，JSON/XML 切换、主备用接口、镜像、播放器下载及历史地址均保留。

## 目录约定

`assets/v2/theme.css` 和 `theme.js` 只用于新页面；共享片段在 `html9/public/v2/`。原 `public/include`、旧 CSS/JS 和未迁移页面保留，避免本轮改造破坏原有会员、口令、支付与嵌入播放器流程。这些保留页面尚未统一为新视觉。

正常链接与动态文本通过 MACCMS 生成并显式转义。复制逻辑按来源容器查询，不依赖连续 ID，也不使用点击量推算集数。图文正文及播放器的既有 HTML 输出保持原业务处理方式。

公共配置在 `settings.php`；不要在此保存密码或接口密钥。修改资源后更新其中的 `version` 以刷新浏览器缓存。采集地址和播放器包均沿用旧站配置，本轮没有重新验证外部服务的可用性。

## 验证

```bash
php tests/theme_compile.php
NODE_PATH=/tmp/maccms-theme-audit-20260909/browser/node_modules node tests/theme_ui.cjs
```

`theme_compile.php` 使用仓库里的 Think 模板引擎和 MACCMS 标签库编译 12 个核心页面，再检查生成 PHP 的语法。`theme_ui.cjs` 用实际 CSS/JS 验证移动分类、屏宽切换、布局、分来源复制、部分选择、倒序和失败回退；剪贴板成功分支使用 stub。

设置 `THEME_PREVIEW_URL` 后可同时检查连接真实数据的独立预览；图片／媒体加载被屏蔽，不能将这些检查视为封面服务、视频实际播放、会员付费或用户报错提交的端到端验收。

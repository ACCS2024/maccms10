# 数据库备份 C2：CLI 流式恢复与前缀边界

范围为 `common/util/DbBackup.php` 的恢复方法、新 `common/util/SqlDumpStream.php`、`command/DbImport.php` 的参数/失败契约及专用回归。后台 A 组 `Database` 解析器没有改动；两条恢复路径暂时保留各自测试，后续如统一解析器应独立提交并重跑 A/B/C 矩阵。

## 已复现与修复

旧 `mac_parse_sql(file_get_contents(...))` 整体载入并多次拆分整份文件；前缀替换还会改写单引号正文中的反引号文本。真实 MySQL 回归验证 ``literal `audit_source` inside text`` 被错误改为新前缀；SQL 执行失败后也会遗留关闭的外键检查。

- 恢复改为 8 KiB 输入缓冲，按完整语句扫描；第一遍词法预检，第二遍执行，不保存整份 SQL 或语句数组。支持普通/版本注释、单引号与双引号、双写引号、反斜杠、带反引号标识符、同行多语句、LF/CRLF/CR、UTF-8 BOM 及旧 CLI 接受的无尾分号完整语句。
- 前缀只改写应用备份 DDL/DML 中带反引号的表名位置及外键 REFERENCES 目标，保留同前缀的业务列、显式普通索引和数据库限定名，也保留字符串与普通注释原字节；可执行版本注释中的表名按相同规则处理。FK/CHECK 的命名约束使用 schema 内共享命名空间：匹配源前缀时，仅这些约束定义及显式 FK/CHECK 名称引用一同映射，避免源表仍在的同库克隆产生 1826 名称冲突；不盲改所有标识符。多个映射取最长匹配前缀，不串联替换；验证前缀类型与字符，兼容 PHP 把数字字符串数组键变为整数的行为。
- 常见独立 SQL_MODE 字面量赋值及保存/恢复变量语句会同步词法状态，实测 NO_BACKSLASH_ESCAPES 前后切换能正确解释字符串。条件版本注释中的模式赋值、无法跟踪的模式表达式以及 ANSI 双引号标识符模式在预检阶段明确拒绝，不猜测版本条件或接受与服务端不一致的词法状态。显式 `DELIMITER` 在预检阶段受控拒绝，避免先执行前面的 DROP 再遇到不支持的客户端语法。
- 空文件、只有注释、未闭合引号/块注释、坏路径、符号链接、读失败均返回受控异常并关闭句柄。未闭合词法结构在执行首条归档 SQL 前拒绝；读取持有共享文件锁。
- 记录并恢复 SQL mode、外键检查、autocommit、客户端/结果字符集及连接 collation；成功和失败均覆盖。已有调用方事务时拒绝导入，防止归档 DDL 隐式提交调用方工作；文件中的完整 BEGIN/COMMIT 正常执行，EOF 仍有活动事务则回滚并报错。
- CLI 显式提供前缀时必须同时提供源、目标，坏前缀返回参数错误，防止缺少一个参数时悄悄恢复到原表名。SQL/运行时失败返回非零退出状态。

## 真实验证

`python3 tests/run_cli_import_audit.py` 使用无网络容器、随机专用 MySQL 8.0 库和固定作者测试 SQL；不加载站点配置、不读取真实备份。PHP **8.3.33 / 8.4.25 各 68 项通过**，包含真实 Command/Input/Output、传统引号格式、正文完整性、表位置/版本注释、源表仍存在时含真实 FK/CHECK 的同库克隆与源数据/结构保留、SQL mode 与字符集恢复、外层事务保护、未完成事务回滚、预检失败不执行 leading DROP、文件及参数错误。

每版另由 `memory_limit=32M` 的独立 PHP 子进程实际导入 **约 48 MiB、12288 条 SQL**，记录的 PHP 峰值内存均为 **6 MiB**。这证明总文件大小不再直接决定内存需求；没有宣称单条巨型 SQL 也只用 6 MiB。

C1 的真实 CLI 导出/恢复回归使用本次新 importer 重新执行，PHP 两版各 **48 项通过**，包括精确类型、生成列、自增零值及 InnoDB 并发一致读结果。

## 明确限制

这是应用表 SQL 备份恢复器，不是通用 mysql 客户端或 SQL 沙箱。归档必须由管理员信任；不支持 `DELIMITER`/任意存储过程脚本，也不宣称解析任意 SQL_MODE 表达式或所有条件版本语法。前缀规则面向应用表备份的明确 DDL/DML 表位置与 REFERENCES，不是通用 SQL AST 改写器，也不自动重写未加引号的表名。未匹配源前缀的任意自定义约束名不自动猜改，同库存在同名约束时仍可能产生语义冲突。

词法预检无法预先判定全部数据库语义错误；已经执行的 DDL/已提交语句无法保证回滚。恢复应在隔离写入的维护窗口进行，不能将文件共享锁视为数据库业务写锁。内存仍与最大单条语句及其注释大小相关，超过数据库 packet 或 PHP 单语句内存能力的输入需另行处理；本 CLI 目前接受普通 SQL 文件，后台 gzip 路径沿用 A/B 验证。

# 数据库备份 B：后台目录、参数、并发与半成品

本组只修改 `application/admin/controller/Database.php`，依赖 A 组已修复的 `common/util/Database.php`。CLI `DbBackup`、SQL 控制台和表优化/维修不在本组范围。

## 根因与修复

真实 Request 调用复现：非空数组 `id` 传给 `date()`、嵌套表数组传给 `strpos()` 均在 PHP 8 抛出 TypeError；已有输出名无法创建时仍返回 `backup_ok`。旧锁先检查文件存在再创建，既有竞争窗口，也在中途失败时遗留占用状态。绝对备份路径在列表和恢复时被 `trim('/', ...)` 变为相对路径，恢复与删除对文件名后缀和缺失卷检查不完整。

- 备份表须为非空字符串并精确存在于当前库元数据；备份工具负责转义合法标识符。去重后保留所有选中表，管理员表排在其他表之后。外部 `start` 只接受 0，时间戳拒绝数组、布尔、浮点、负数和溢出值。
- 配置路径接受绝对目录或 ROOT_PATH 下的相对目录，拒绝无效类型、控制字符、流包装器和父目录跳转；目录创建失败变为原协议错误。新建目录权限 0700，未读取任何站点真实配置。
- 导出、恢复、删除共用非阻塞 `flock`。`backup.lock` 的存在不代表持锁，文件 inode 保留，所有正常成功/失败路径关闭持锁句柄；旧进程退出后的无锁文件可再次使用。锁文件符号链接、硬链接或 inode 被替换均拒绝，避免截断目标文件。
- 导出先进入私有随机暂存目录，检查创建、分页导出与关闭结果，再使用同文件系统排他硬链接发布各卷。新卷不会覆盖旧归档；失败仅清理本次拥有的文件。完成前保留 `.时间戳.pending` 标记，最后发布 `.时间戳.json` 清单后才移除标记、返回成功。
- 新清单记录所有卷的准确名称、大小与 SHA-256；恢复先检查全部卷及摘要，再执行第一条 SQL，可发现缺失尾卷或同长度篡改。列表不重复计算全文件摘要，只检查卷号、清单、大小与完成状态。
- 旧正常 `.sql` / `.sql.gz` 没有新清单仍兼容；新 A 格式须带对应清单，不能删除清单后降级为旧格式。严格文件名、连续卷号、一致压缩方式及普通文件检查阻止宽泛 glob 后缀、目录或符号链接进入恢复。删除允许清理损坏/未完成归档，但只接受精确匹配的普通文件；失败不报成功，后续可继续删除剩余文件。
- 恢复与删除显式要求 POST，与现有 `admin_common.js` 的 `$.post` 操作一致。保留继承的后台鉴权与原响应 code/message 契约。

## 验证

`python3 tests/run_admin_database_audit.py` 创建随机专用 MySQL 8.0 数据库与无网络容器，仅运行仓库固定测试 SQL 和自身生成的临时备份，未访问站点配置或现有备份。测试使用真实 Request、控制器动作、备份工具和 ORM；仅绕过构造函数中的站点鉴权/模板初始化，通过独立测试控制器捕获正常返回值。

PHP **8.3.33 与 8.4.25 各 130 项检查通过**，包括真实多卷普通/gzip 导出恢复、旧格式恢复、绝对/相对目录、正常与带反引号的合法表名、类型坏值、时间戳碰撞、尾卷缺失、同长度破坏、缺清单、混合压缩、链接、三动作实际锁竞争、未持锁旧锁文件、失败清理与可重试删除。第二卷发布、清单写、锁写及 unlink 失败通过仅作用于系统调用边界的注入模拟；真实视图导出失败验证工具返回 false 能被完整处理。

## 运维边界

- 当前后台一直是单次 POST 内遍历所有表与全部分页；静态 JS 没有跨 HTTP 续传，本次保持该契约。大任务受 PHP/FPM/代理超时影响，不宣称后台异步任务或断点续传能力。
- `flock` 只协调本控制器的备份/恢复/删除，不阻止网站、采集、定时任务或其他数据库客户端写库，也不与 CLI 共享锁。当前没有一致性快照；若要求此方式生成逻辑一致备份，须在维护窗口暂停所有写入者，完成备份后再恢复写入。恢复同样需要隔离写流量，失败后已执行 DDL 不保证回滚。
- 正常异常路径清理已验证。进程被强制终止时 flock 随句柄关闭释放，pending 防止半成品被列为可恢复归档；隐藏暂存目录可能残留，需要维护人员核对后清理。本测试模拟 pending 状态，未宣称验证断电持久性或文件系统级原子事务。
- 新备份移动/保留时必须一起保留对应隐藏 JSON 清单；清单大小上限 1 MiB。目录所在文件系统须支持普通文件硬链接，否则返回失败并清理本次产物。
- 旧无清单备份缺失最终一卷无法仅靠现存连续卷号判断；新格式已补全此检查。归档 SQL 仍是管理员可信输入，导入功能不是 SQL 沙箱。

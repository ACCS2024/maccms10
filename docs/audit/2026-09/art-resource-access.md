# 文章正文、分页与密码授权

本组只闭合文章当前正文的公开出口，复用已提交的视频身份和密码工具；视频原有方法保持不变。文章列表元数据的发布/回收一致性、漫画章节、采集导出信任边界是后续独立组，不作为本组完成事项。

## 已复现的根因

在临时 MySQL、真实 Request/User/JWT/Ulog/Art 与当前安装表结构下，PHP 8.3、8.4 均复现：

1. VIP 未验证 `art_pwd` 仍能通过 `get_read_page` 取得正文。
2. 接口先按请求 page=200 查询购买凭证，之后才把页码收敛到实际 page=3，导致错误坐标的凭证授权另一页正文。
3. 前台密码详情模板收到原始密码及所有章节正文，模板中的隐藏逻辑不能保证这些数据不会在其他主题或出口显示。

原始证据为 `art-resource-repro.log`，每版三个真实根因复现。公共旧 Ajax 列表、RSS、旧主题详情直接显示正文、空简介时 SEO 回退到正文，也是必须同时处理的同类出口。

## 稳定解析与响应合同

`ContentResource::artContext(array $freshRow, array $params): array` 只解析服务器新鲜记录。成功返回 `code=1,id,page,page_total,previous_page,next_page,current,points,whole,ulog_mid,ulog_type,ulog_rid,ulog_sid,ulog_nid,purchase_supported,purchase_page`；`current` 含内部正文，不能整包序列化给未授权客户端。

ID 和显式页码接受 1 至 4294967295 的十进制整数，缺省 page=1。数组、零、负数、浮点表示、科学计数法及 UINT32 溢出均受控拒绝。保留旧的“超过末页则读末页”行为，但先收敛再授权、报价和构造响应；响应 page 始终是实际页。正文不存在返回明确错误，正文字符串 `0` 是有效单章。空章节保留原始序号，不能重新编号后查询另一章凭证。空章不提供购买，整篇购买跳过空章选择第一篇实际正文；字符串 0 仍视为正文。

价格保留现行合同：整篇模式用 `art_points`，单章模式先用 `art_points_detail`，为零时回退 `art_points`。免费零价合法，非法价格不隐式转成免费。购买类型为 mid=2/type=1；单章 sid=实际 page、nid=0，整篇 sid/nid=0。价格仍参与旧购买凭证匹配，本组不改变调价后的历史凭证语义。

当前凭证 schema 的 sid 是 TINYINT UNSIGNED，最多 255，points 最多 65535。合法第 300 章仍可由免费规则、VIP 或整篇凭证访问，不截断成第 255/44 章。不能表示的单章购买返回 `purchase_supported=false`，前台不显示可执行购买按钮。整篇购买用 `purchase_page` 选择第一个真实非空且可表示的起始章节，正文 page 保持不变，服务器最终存储 sid/nid=0；若起始选择也不可表示则明确不提供购买。字段扩容和写方锁内重核由独立购买/迁移组处理。

API `get_read_page` 保留 `code=1` 下的 `can_read,deny_code,deny_msg,points_hint,art_id,art_name,page,page_total,title,note,content_html,has_prev,has_next`，新增 `password_required,password_help_url,purchase_supported,purchase_page`。拒绝时 `content_html=''`，成功仅返回获准当前页，前后页不带正文。`get_detail` 保持免费目录 DTO；详情和相邻目录排除未发布及回收记录。`verify_pwd` 支持 `art_id`（兼容 `id`）与字符串 pwd。

## 组合授权与前台出口

All 的文章方法先读取已发布且未回收的新鲜行、确定真实数字 ID/页码，再按同一坐标检查可信用户的分类组权限、服务器价格与本人购买凭证，最后检查文章访问密码。正常资源读取不扣费、不创建购买记录。保留文章原有的特殊合同：无分类阅读权限的用户仍可通过本人对应的付费章节凭证读取；不机械套用视频的另一套分类规则。

文章详情和阅读共用 `2-1-{id}` 密码作用域；密码验证不等于支付，VIP 也不能跳过密码。新会话授权绑定作用域和当前密码指纹，改密码会使旧授权失效，旧字符串 `1` 或其他视频/文章的授权不会被接受。游客可通过现有 Ajax 密码入口验证，随后在同一会话读取；新 API 验证动作使用相同工具。纯 Bearer 只代表身份，密码状态仍要求客户端保留会话 Cookie。

模板投影只保留获准当前页的正文。其他页的标题、备注、序号、站内阅读链接保留，但正文为空；聚合 `art_content` 也只包含当前页，原始密码改为布尔提示，获取密码 URL 保留安全协议。RSS 与静态详情始终只用公开简介/目录，即使生成者是已验证密码的 VIP，也不能写出正文。旧 Ajax `data(mid=2)` 经过公开 DTO，不再带密码或正文。SEO 无公开简介时不再读取正文作为摘要。

默认 reader 继续使用现有模板和购买控件；缺少 `art/read`、`art/detail_pwd` 或 `art/ajax_detail` 的主题使用独立站内兜底模板；缺少 `art/rss` 时使用仅含公开简介和章节链接的独立 RSS 模板。该模板包含可用的密码、阅读、章节目录和购买入口，本地外部 JS 用实际表单坐标完成密码 POST 或 `write_token` → 带 CSRF 的购买 POST，服务端决定价格与用户。无 JavaScript 时密码表单仍使用 POST，不把密码放入 URL。失败只显示纯文本提示；重复提交在响应前禁用，成功后刷新以重新验证资源权限。默认购买 widget 只修改 Art 分支的 `purchase_page` 获取，不改其他媒体。

旧主题详情在无正文权限时显示动态阅读入口；普通免费文章仍按规则显示当前正文。静态详情保留公开目录和动态阅读链接，实际 Make/info/buildHtml 已验证生成三页安全文件。旧站点已生成 HTML/CDN 副本不会被自动删除，上线须清除或隔离含原始正文的旧副本，再重建。

## 验证与边界

运行 `python3 tests/run_art_resource_audit.py` 使用一次性 MySQL 8.0、网络关闭和 Unix socket；每版分别验证根目录和 `/fixture/sub/` 部署。PHP 8.3.33、8.4.25 每个路径通过 714 项真实 PHP/MySQL/模板/文件检查，实际渲染 HTML 与本地生产 JS 每次通过 41 项 Node 检查。覆盖普通用户/VIP/多组/禁用/过期身份、真实 Cookie/Bearer、跨用户/类型/文章/页/价格凭证、整篇/单章/免费、越界/非法/长章节、旧缓存、独立密码作用域及更改失效。

真实 View facade 已验证活动主题缺文件时的绝对兜底路径；ThinkPHP 渲染包括整个兜底页、默认购买 widget、旧密码页、五个旧主题正文块和三个 RSS 出口；实际 Make/info/buildHtml 在临时站点目录写文件，并明确移除前台用户上下文模拟后台生成。JS 检查执行生产脚本，验证 token GET → 单次 POST、密码特殊字符编码、正确作用域、保留会话、无客户端价格或用户 ID、失败不误报成功和不可购买按钮缺席；这是自动化 DOM/网络替身验证，没有访问真实站点或发送媒体请求。实际 Ajax 密码写入会话与后续 API 回读在 PHP/MySQL 中另行验证。购买余额事务及锁内资源重核由根代理购买组负责，本组不声称已替代那组验收。另复跑已提交视频矩阵两版各 3018 项、JS 38 项；公开 DTO 矩阵各 600 项、JS 13 项，非 mac_ 前缀矩阵各 400 项均通过。

## 明确留待后续的审计项

- Art `get_list` 的默认发布条件、`get_latest/get_hot` 的回收条件以及另外两媒体的公共列表状态，将紧接本组独立修复。采集导出是单独信任边界，不能按公共展示列表机械处理。
- 视频静态路径配置若缺少 `{id}`、`{en}`、`{md5}` 等唯一标识，不同视频可能沿用同名文件；这是配置碰撞风险，需要独立检查和迁移方案，不能自动猜测重命名现有站点路径。
- 全局 `mac_substring` 的旧字节判断在 PHP 8 下把 ASCII 文本变成空格，且不支持四字节字符，由根代理独立修复。本组 RSS 仅在自身摘要处改用 `mb_substr`，保持本地摘要处理；全局修复已经独立提交于 c425926。
- 富文本存储/输出的 HTML 安全策略、第三方主题脚本行为，以及可能已经外发的原始正文副本不属于此次读取授权证明。

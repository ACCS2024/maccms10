# 旧 Ulog 页面缺模板

默认主题以及仓库其他主题均无 `user/ulog.html`，当前导航使用 favs/plays 等专用页面。旧 `User::ulog` 动作仍可被访问，并在登录后抛出 TemplateNotFoundException，形成 500；将它重定向 plays 会丢失原来的通用类型筛选语义。

动作现在使用当前 TP8 视图引擎先检查模板：无模板返回明确 404，并在查询私有日志前结束；自定义主题提供该模板时继续原有查询、分页及渲染，不新增菜单或替换列表内容。

`tests/framework_audit_ulog_template.php` 使用实际 TP8 视图引擎与临时自定义模板，验证默认主题和空主题的 404、缺模板不查日志，以及自定义模板输出/用户归属/类型筛选。两版 PHP 各 6 项通过；原真实 Request/ORM 会员列表 43 项仍通过（该旧列表测试本就隔离渲染，模板可用性由本组单独验证）。

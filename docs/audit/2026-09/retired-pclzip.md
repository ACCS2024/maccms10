# 移除未使用的旧压缩库

移除 `application/common/util/PclZip.php`。对当前仓库跟踪文件的文本引用检查只发现后台 Update 控制器的一处说明性注释，没有发现业务代码调用。该注释记录已停止使用的在线下载/覆盖更新机制，保留其说明。

旧库仍使用 PHP 4 风格构造函数；审计中的隔离验证还发现指定解压目录约束后，异常条目路径及目标目录已有符号链接可以使写入越过目录边界。未发现连接这些行为的当前 HTTP 可达调用链，不将库级问题描述成已证实的远程利用入口。

当前本地插件管理不调用此库。移除后验证本地插件生命周期回归，以及隔离站点的插件与更新管理页面。历史代码可通过本次独立 Git 提交恢复审阅；不保留可执行副本到部署目录。仓库外自行编写、直接引用该内部类的插件需要迁移其压缩功能。

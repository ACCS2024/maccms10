# AI 封面生成与恢复事务

生成响应先经过有大小上限的 HTTP 客户端和真实图片解码，再生成全部水印/缩略图。文件进入现有附件流程：远端传输在事务外完成并登记独立存储意图；随后一个短事务同时写 Annex、视频主图/缩略图、原图备份和远端引用。生成开始时读取主库快照，写入时锁行并比较图片、回收状态和生成提示词相关字段。视频被删除、回收或其他编辑修改后，旧生成不得覆盖新状态。

需要先执行 [备份字段迁移](ai-cover-backup-schema.md)。缺少字段会在付费生成请求前停止。普通编辑和导入不能提交原图备份字段。首次生成备份完整图片组合，重复生成保留首次备份；无缩略图时写空字符串。恢复同时写主图和缩略图，也支持原本两者为空的情况。历史记录只有主图备份而缺少缩略图证据时，保留旧值并要求人工确认。

事务提交确认丢失时，响应含 `retryable=false` 和核查编号；生成文件及私有 `maccms-attachment-*/manifest.json` 保留，存储意图记录真实的传输结果。不得只根据错误响应删除文件或自动重试。应通过编号、目标视频、Annex 和存储意图的引用状态核对实际提交结果。单请求内的下一次操作会被阻止。跨请求的持久化操作幂等键、自动对账队列仍需另行实现。

已确认提交后，缓存或搜索索引异常只记录脱敏诊断，并返回 `maintenance_pending`。它不改变成功的写入结果。恢复和失败路径均不删除历史文件。

回归 `tests/framework_audit_vod_cover.php` 使用真实解码和 ORM/PDO，外部图片生成与存储只替换为普通图片夹具。覆盖本地/远端、全部缩略图登记、完整原图恢复、历史备份保留、并发编辑/删除/回收、上游返回形态、处理失败、数据库拒写与存储值改变、缺少迁移、调用方事务保全和提交后维护失败。独立 SQLite 文件与第二连接核对提交前/提交后丢确认的物理结果，包括生成、远端引用及恢复。测试已加入默认和 MySQL `remote_upload` 套件。

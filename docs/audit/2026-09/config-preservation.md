# 请求期间保留配置与审计证据

旧 Begin 中间件逐请求删除 extra/ 中不在白名单的文件；addons.php 超过 2048 字节或出现一组敏感单词时，自动改名并覆盖为空配置。较长的合法插件 Hook 配置、数据字符串中的关键词都会误触发，先前隔离文件下次请求又可能被未知文件删除逻辑清除。

当前 TP8 由 config/*.php 显式 include 所需 extra 配置，应用初始化在 Begin 中间件之前完成。因此后置扫描既不能阻止已经发生的配置代码执行，也不能被当成病毒清除边界。

本批保留检查日志，改为 REVIEW 提示；请求期间不再删除、改名或覆盖配置。文件名以 JSON 转义后写入日志，避免换行破坏记录。SelfCheck 同步提示核对来源和加载方式，不再建议仅为了阻止自动删除而盲目扩展白名单。

`tests/security_audit_config_preservation.php` 在两个 PHP 版本各验证 14 项：保留自定义配置、合法长 Hook 配置、历史隔离证据、异常文件名、既有配置；日志不可写时仍保留所有文件并继续请求。该测试只操作随机临时目录。

日志是人工复核线索，不判断感染与否。部署取证应先保存可信副本和摘要，再离线核对文件、数据库内容、服务配置及计划任务；审计当前仓库不能证明外部部署环境无恶意残留。

# CLI 运行目录清理结果

`cache:flush` 逐项检查 `runtime/cache`、`runtime/temp` 和显式指定的 `runtime/log`。实际删除失败、路径变成普通文件或链接配置无法安全处理时，继续处理其他目录，最终返回退出码 1；全部完成或目录已经不存在时返回 0。

根目录符号链接只移除链接条目，输出明确说明目标目录未改动。OPcache 信息仅描述当前 PHP CLI 的重置请求，并检查函数返回值；这条命令不负责清空 Redis、Memcached 或 PHP-FPM 的缓存。

验证使用实际 ThinkPHP 命令和隔离临时文件，PHP 8.3.33、8.4.25 各通过普通模式 8 项检查，以及 UID/GID 65534 下 11 项检查。非特权模式真实制造目录权限不足，验证非零退出码、失败信息和恢复权限后的重试；其余检查覆盖日志选择、重复调用、普通文件误配置、目录链接与断链。普通模式加入默认审计入口。

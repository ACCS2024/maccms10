# 审计参数的编码、脱敏和容量

已在 `8f3ec76b` 的实际旧 sanitizer 复现：700 个普通“中”字经 2000 字节 substr 截断后，字段成为非法 UTF-8，整份 json_encode 返回 false。旧逻辑还会直接截断最终 JSON，产生无法解码的日志；递归与字段数量没有共同上限。

新增 AdminAuditPayload 编码器，保留合法字符边界，以完整 JSON 表达截断或省略。新记录采用 version=2、data、truncated 包装，普通字段保留值和类型；已有日志不重写，原详情页仍按文本展示，加密和历史解密格式保持不变。密码确认、passwd、pwd、authorization、cookie、session、credential 等字段补入脱敏范围，敏感键的整个子结构一并遮蔽。自定义脱敏配置无效时省略参数，避免回退成未按配置脱敏的内容。

遍历最多 1024 个节点、8 层嵌套，键至多 128 字节，字符串至多 2000 字节，共享原文/结构预算 8192 字节；最终明文 JSON 不超过 16384 字节。转义膨胀超限时用完整的省略记录替代，不截断 JSON。非法文本、对象及非有限数值用显式标记替代，不触发对象序列化。该限制作用于已经解析的请求数据，不能代替请求接收阶段的字节上限。

PHP 8.3.33、8.4.25 各通过 96 项检查，包含长中文/表情、嵌套敏感参数、自定义配置异常、深度/宽度/循环引用、转义膨胀和对象拒绝。测试另外启动隔离 PHP HTTP 服务，真实 AdminAudit 中间件与 AdminAuditLog ORM 将记录写入私有 SQLite，验证 HTTP 202 响应保留、查询令牌未进入 URI、参数脱敏、加密解码和弱密钥时禁止降级明文。默认审计入口包含这组测试。

本批只修复参数编码链。中间件配置开关和元数据形状、日志写入失败可观测性、管理员退出/异常响应的事件覆盖、日志读取权限与展示，以及生产保留策略仍需独立审计。按字段名脱敏也不能识别任意普通正文中嵌入的秘密。

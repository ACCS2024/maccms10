# 前台访问检查的提前响应

Base 中的站点关闭、地区限制、浏览器提示、列表/搜索/异步功能关闭和验证码页，通过框架响应异常结束分发，取消直接 echo/exit。AJAX 错误保留 JSON 对象，HTML 验证提示保留当前模板。未知 action 交给框架返回 404，不再先输出一段重定向脚本再触发错误页。

地区查询的异常捕获只包围查询本身；禁止访问的响应在捕获范围外抛出，避免被原来的宽泛 Exception 捕获吞掉。删除与实际省份查询器无关的 GeoIp2 异常分支，保留现有查询失败时的策略。浏览器识别改为明确的字符串包含判断，补齐 `QQ/` 位于首字符时漏判的情况。

`framework_audit_frontend_gates.php` 在真实 Base/All、Request、Response 和本地省份查询器上验证 88 项通过/停止分支，模板展示与会话读数使用普通夹具。与构造函数中间件测试共同覆盖响应如何返回以及守卫是否阻止后续执行。公共页面缓存、资源权限路径与流式采集另行处理。

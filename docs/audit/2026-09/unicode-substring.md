# 共用文本截取：PHP 8 字符处理

`mac_substring` 原先逐字节转二进制，再用宽松数字比较猜测 UTF-8 长度。填充字符串带空格，ASCII 分支会比较空格与数字 0；PHP 8 的比较结果让英文、数字、常用标点落入空格分支。该实现也不识别四字节字符。它被搜索词长度限制、多个内容模型自动摘要、微信内容说明、模板及 SEO 调用。

本组使用明确 `UTF-8` 的 `mb_substr`，不依赖进程的 `mb_internal_encoding`。保留既有 `mac_scalar_string` 输入转换合同；截取长度和起点接受非负整数及十进制整数字符串（含前导零）。零长度、越界起点返回空串；数组、对象、布尔、负数、浮点、小数/科学记数法文本和整数溢出坐标返回空串。畸形 UTF-8 用 `mb_scrub` 修复后截取，替代符遵守当前 mbstring 设置。这里按 Unicode 码点计算，未增加字素簇/视觉字符宽度语义。

真实安装表单还把 `SCRIPT_NAME` 的字节索引传给字符截取函数，中文目录会截入脚本名。该调用改为对应的字节切片，保留 ASCII、中文及 emoji 目录；没有可用脚本路径时使用根目录。

`tests/core_audit_substring.php` 的 58 项覆盖 ASCII、中文、希腊文字、emoji、组合字符、起点/长度边界、坏参数、全局编码变化与坏 UTF-8；实际调用搜索长度限制、SEO 空摘要回退、ThinkPHP 模板表达式及安装控制器 step3。没有修改内容字段的发布/权限策略，也不回写历史已损坏的摘要；历史摘要重建应作为单独数据修复计划处理。

# 内置 IPv4 查询输入

`ip_limit\IpLocationQuery` 的自动加载正常，数据位于当前仓库。旧 `ipToInt()` 对四个段直接 `intval`，例如 `1.0.1.junk` 会变成 `1.0.1.0` 并获得省份；数组、对象等输入还可能在 PHP 8 的字符串操作处抛错。本批在整数转换前验证字符串类型和规范 IPv4，其他输入继续返回既有“未知”结果 `''`。

没有修改、重新排序或更新内置数据，也没有把 IPv6 当作 IPv4。33 项回归覆盖类型、非法地址段、真实范围端点及间隙，并检查全部 18,986 个内置区间的排序、非重叠、整数范围及省份键，其中 18 个显式 UNK 区间保留未知结果。结构检查不代表地理数据仍然准确或新鲜。

当前区域限制入口使用客户端 IP 工具，不能仅据这个内部解析缺陷宣称存在可直接利用的公网请求路径。`GeoIp2\Exception\AddressNotFoundException` 是调用处遗留的 catch；现有查询类并不依赖 GeoIp2。本批不改变 IPv6/未知归属的区域限制策略，相关产品规则和数据维护仍是独立后续项。

# 百度 URL 推送适配器

## 协议核对与外部限制

百度搜索资源平台的[普通收录手册](https://ziyuan.baidu.com/college/articleinfo?id=267&page=2)说明，接口使用 `/urls`、`site` 和 `token`，请求正文每行一个网址、每次最多 2000 条；HTTP 200 的 `success` 是成功推送数，`remain` 是当天剩余配额，拒绝列表可选。手册当前公开示例仍使用 HTTP。具体配额依站点而异，不能从示例数字推定本站每日配额，也不能将成功数量解释为已接受输入数组的前 N 项。

2026-09-10 在本审计环境对 `https://data.zz.baidu.com/urls` 进行一次**无凭据、无网址正文的 HEAD** 验证，默认信任链和主机名验证返回 `curl (60): no alternative certificate subject name matches target host name 'data.zz.baidu.com'`。这是该环境、该时间的观察，不能据此断言所有部署或未来证书状态相同。没有实际向百度提交任何网址或 Token，也没有验证生产提交成功。普通适配器固定使用 HTTPS，保持主机名与证书验证；如果实际环境也无法通过验证，会明确提示安全连接失败并建议使用平台手动提交，不回退明文 HTTP。

百度[2024 年公告](https://ziyuan.baidu.com/wiki/3546)明确旧“快速收录”于 2024-04-26 下线并回收原配额。[新“快速抓取”说明](https://ziyuan.baidu.com/college/articleinfo?id=3549)要求相应站点权益，并使用平台下发的最新接口。本组保留 `Baidufast` 类、名称和原有配置兼容，但返回受控下线错误，执行零次网络请求；不把快速 Token 送往普通接口，不虚构新快速抓取地址。

## 修复与返回契约

- 保留普通配置 `urlsend.baidu.token`、`site.site_url`、`http_type`。站点已含 HTTP(S) 协议时直接校验，避免拼出双协议；不重写用户配置。网址数组、嵌套输入、凭据、站点根地址、批次数量及换行均在网络请求前校验。
- 每次 `submit` 最多发出一次 POST，同批完全相同的网址去重；Token 和站点使用 RFC 3986 查询参数编码。固定服务地址、HTTPS 协议、证书及主机名验证、关闭代理继承和所有重定向、连接/总超时、响应头/正文大小限制共同约束该专用请求。
- 根据真实 HTTP 状态码处理失败，拒绝缺失、负数、类型错误、超出提交数或互相矛盾的统计。错误消息只使用本站固定说明及整数 HTTP 状态，不返回最终请求 URL、Token、远端消息原文、拒绝网址列表或原始响应；未知响应不能以成功格式显示。
- `code=1` 表示本批全部获得成功确认且配额未耗尽；附带 `success`、`remain`、`submitted` 及两类拒绝数量。`code=103` 表示部分未确认或配额耗尽，仍保留实际确认的数量。现有后台/定时调用在非 1 时停止，因此不会继续推送后续页，也不会按数量猜测网址顺序、写入适配器 `_lastid` 或重发前 N 条。即使本批全部成功，配额为 0 也返回 103 停止状态，消息明确说明本批成功数。
- `code=100` 为本地参数/配置错误；101 为传输、格式或统计无法确认；102 为 HTTP/平台拒绝；105 为旧快速收录退役。传输中断或超时后可能已经送达，故不自动重试，不宣称跨调用恰好提交一次。

## 验证

```sh
python3 tests/run_baidu_urlsend_audit.py
```

测试临时创建 CA，以及正确/错误主机名证书，通过 Unix socket 运行真实 HTTPS 服务；PHP 容器网络完全关闭，仓库只读挂载。测试仅注入临时连接 socket 和 CA，生产的 HTTPS 目标地址、主机名验证、请求体、状态处理与重定向设置都实际执行。所有 Token 和网址均为固定假数据，测试结束清理服务、证书和日志。

覆盖真实 HTTP 成功和失败、缺失/异常字段、恶意远端原文、部分成功与额度耗尽、发送次数、同批去重、无效配置及已有协议、Token 编码与结果保密、三类重定向、受信任但错误主机名/不受信任证书、响应上限、提交后断连和超时，以及旧快速渠道零网络调用。PHP 8.3.33 / 8.4.25 各通过 231 项检查，三个 PHP 文件的双版本语法检查通过，两个适配器的目标 PHPStan 检查无诊断。

本组没有接入登录后才可获取的新快速抓取接口，没有访问生产 Token、配额或账户页面；没有覆盖整个后台取数、页面跳转、定时任务授权及跨批次持久化去重。HTTPS 服务的实际可用性仍由官方证书及部署环境决定。

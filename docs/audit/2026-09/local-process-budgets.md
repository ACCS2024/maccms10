# 本机工具进程公共边界

从后台监控提取 LocalProcess，增加有界 stdin，供后续 OpenCC 等固定本机工具复用。命令只使用 argv，拒绝错误类型、NUL、超量参数和越界预算，不接受请求拼接的命令。默认 500 ms、stdout/stderr 合计 64 KiB；最长允许 10 秒、输入 8 MiB、输出 16 MiB。调用方必须按用途选择更小的界限。

同时非阻塞写入输入、读取两条输出流，避免任一管道填满后相互等待。只有 stdin 已全部写入且已启动的进程正常退出才返回 stdout；失败/超量/超时返回 null，不发布部分文本。异常路径关闭管道并终止、回收已启动的进程。成功的空输出与失败 null 分开。

Linux 上的真实子进程回归验证普通 UTF-8/换行传输、独立 stderr、非零退出、大量 stdout/stderr、停滞、输入未传完和禁用函数降级；系统监控继续使用此实现，既有 79+10 项保持通过。本批未运行原生 Windows 管道，跨平台阻塞细节需在该平台验收；该工具不等于任意进程树隔离器，正式调用仅限已知本机程序。

# 视频静态播放、下载的安全动态跳转

本组承接 `06e2bd2` 的视频授权修复，恢复该提交暂时阻断的 Make 静态播放、下载生成。静态详情继续使用安全目录。文章、漫画授权属于后续子批；本报告不把其他媒体、采集导出或旧站点缓存视为已完成。

## 恢复的功能合同

| 设置 | 实际生成产物 | 资源选择 |
| --- | --- | --- |
| view 2 | 每条视频一个播放/下载 HTML | 保留旧 `?id-sid-nid`；无选择参数时使用排序后第一个真实非空资源 |
| view 3 | 每个真实非空来源/集一个 HTML | 固定该文件的实际 sid/nid，不根据压缩后的数组序号重新编号 |
| view 4 | 每个非空来源一个 HTML | 保留旧 `?id-sid-nid`；无选择参数时使用该来源第一个真实非空资源 |

播放和下载分别应用对应设置。来源为空或集内存在空段时跳过空项，不访问不存在的下标；全部为空时后台明确显示跳过。正常路径、静态链接命名以及生成进度协议保持不变。

HTML 只包含固定文字、公开数字坐标和站内入口，不含媒体原址、密码、播放器/服务器配置、用户信息或已授权正文。生成者即使已登录 VIP 且验证密码，也不会把个人授权结果写成公共文件。页面使用本地 `static/js/vod-resource-redirect.js` 和严格 `data-*` 属性，没有内联脚本，不要求 CSP 放行 `unsafe-inline`。禁用 JavaScript 时仍可点击默认的动态入口；view 2/4 的旧查询选择依赖 JavaScript，没有脚本时入口指向文件的首个真实资源。

脚本仅接受三个 1 至 4294967295 的十进制整数，不接受数组式查询、附加参数、外部地址、零值或溢出值。错误选择明确停止跳转，不回退到另一集。生成文件只引用当前部署目录下的本地 JS；不引用外部服务。

## 授权入口与写入边界

`index/Vod::resource` 是显式数字 ID 的动态入口 `/index.php/vod/resource?id=…&operation=play|down&sid=…&nid=…`。它不再次套用静态地址或名称/编码 ID 转换，因此不会跳回自身的静态文件。每次从数据库重新读取已发布记录，再复用 `label_vod_play` 的真实坐标、可信用户、分类权限、服务器价格、本人购买记录与相应独立密码检查。当前播放、完整下载目录逐项授权及相邻集规则沿用视频组，不复制第二套授权逻辑。该入口不属于匿名公共目录，响应为 `private, no-store`。

`StaticVideoRedirect` 只负责选择公开坐标、生成固定页面、发布 HTML。静态路径必须在当前部署根和 URL 前缀内，只允许 HTML 类扩展名、合法目录段，拒绝外部地址、穿越、代码目录和目录/目标符号链接；合法中文目录保留。每个文件先排他创建临时文件，确认写完后原子替换请求生成的目标。失败时 Make 返回错误，不宣称成功，也不提前推进该批生成时间。此保证按文件生效，不是全站事务：本批后续文件失败时，已经生成的安全跳转页可保留，重跑可覆盖。

不会删除未请求重建的旧 HTML，也不会清理线上 CDN。部署必须先清除或隔离旧的含原始资源 HTML/CDN 副本，再重新生成；仅上线 PHP 与 JS 不能撤销历史副本。缺失、不再存在的来源或章节对应旧文件同样需部署清理，不能误认为本轮空资源跳过会自动删除它们。

# 公共 API 与采集授权入口

公共 API trait、Provide 六类资源及 SeaCMS 视频接口共享 `ApiAccess`。关闭、配置异常和授权拒绝使用 `HttpResponseException` 返回框架响应，替换入口中的 `echo/exit/die`。关闭或无效配置为 HTTP 503、正文保留 `closed`；身份未授权为 HTTP 403、正文保留 `api/auth_err` 对应语言文本。拒绝响应声明纯文本和 `private, no-store`，正常经过会话及安全响应中间件，不继续执行内容查询。

开关只接受整数或字符串 0/1，非法配置不能通过宽松比较开启接口或关闭授权。授权配置限定为字符串、最多 16 KiB、128 个条目及 32 个不同域名；兼容 `#` 和 textarea 换行分隔。IP 按规范格式比较，支持 IPv6，保留本机 IPv4 回环并支持 IPv6 回环。必须存在合法原生连接地址，再通过统一 `ClientIp` 可信代理策略取得实际客户端，拒绝缺失/无效地址及无身份意义的全零地址。任意客户端声明的转发头不能直接变成授权身份。

域名格式先校验、去重并使用绝对域名解析，只有有效 IPv4 DNS 结果能授权相同地址，解析失败拒绝。本批保留旧域名授权的 IPv4 DNS 语义；输入规模限制不等于解析总时长保证，原生解析的超时/缓存治理仍需单独完成。未声称通过这一步完成整个出站网络审计。

`PublicApi::check_config` 改为受保护的内部方法，实际 ThinkPHP 路由访问该动作返回 404。采集接口成功输出路径、XML 组装及内容筛选不混入本次变更，仍继续审计。

验证使用真实 Cash/Actor 构造、Provide/SeaCMS 入口、ThinkPHP 响应管线、SessionInit 和 SecurityHeaders，覆盖配置形状、授权/拒绝、IPv4/IPv6、可信代理、无效源地址、条目边界、域名去重/失败以及内部动作路由。DNS 测试使用确定性替身，不对测试域名实际发起解析；其余 API、账户和财务回归及双版本完整默认审计检查共享 trait 的影响。

# 首页重设计：沿用老站结构

用户否定了第一版通用目录式布局，要求参考原站思路重做。本版替代第一版作为当前视觉方向。

预览地址：http://85.149.233.2/theme-preview-20260909-a7c4/v2/index.html

保留原站 Logo、顶部搜索与统计、青蓝色横向导航、七组分类、首页公告与接口，以及封面／名称／类型／更新时间四列资源表。没有将首页拆成多个产品页面，也没有新增宣传型大标题。

调整集中在原结构内部：分类改为紧凑对齐的七行；站点信息与接口并排；接口按行展示，通过 JSON/XML 切换格式；镜像保持可复制；历史信息仍在首页展开；列表去除每行卡片阴影，统一列宽和分隔线。手机端一级分类改为可横滑 Tab，点击后仅显示对应子分类；支持左右键及 Home/End 切换。公告与接口仍可展开查看。

原型包含搜索、分类、排序、分页、紧凑列表、详情示意、公告入口、接口格式切换与复制。接口为原站公开配置，不代表已验证其可用性。片名、封面及子分类为展示样例；统计使用读取时快照。生产数据、PHP 模板和后台未改动。

本地文件：`index.html`、`style.css`、`script.js`、原站 `assets/logo.gif`。服务器只部署上述静态预览文件，未切换生产主题。

浏览器检查见 `evidence/verification.json`，覆盖 1440、1024、768、390、360px；五种宽度均无页面级横向溢出。还检查了移动分类 Tab 与接口展开、时间列不换行，以及搜索、分页、筛选、详情和复制反馈。剪贴板成功分支使用 stub；权限拒绝时回退为手动复制。

截图：`evidence/home-1440.png`、`evidence/home-390.png`。原主题读取及源码诊断保留在 `../m1938pc3-audit/`；其中第一版原型和拆分首页的方案已经被本轮方向替代。
